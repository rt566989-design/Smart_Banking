🛡️ Compound Trigger & Daily Cap Sentinel

Bypasses ORA-04091 Mutating Error
Why standard row triggers fail (ORA-04091): When a row-level trigger tries to run SELECT SUM(amount) FROM TRANSACTIONS WHERE from_account = :NEW.from_account, Oracle throws a Mutating Table Error because the table is actively changing.
ADBMS Solution: Our Oracle COMPOUND TRIGGER stores affected accounts in memory across AFTER EACH ROW and evaluates the aggregate daily ceiling in AFTER STATEMENT once the table is unlocked!

🚨 Autonomous Security & Fraud Alerts (`FRAUD_ALERTS`)

PRAGMA AUTONOMOUS_TRANSACTION

In ADBMS, Autonomous Transactions allow subprograms to commit independent transactions without affecting the main transaction. When an overdraft or malicious attempt happens, the main financial transfer is ROLLED BACK, but the security audit log in FRAUD_ALERTS is PERMANENTLY COMMITTED!

🚀 Bulk Monthly Interest

BULK COLLECT & FORALL

Traditional row-by-row cursors ("slow-by-slow") incur high CPU overhead switching between the PL/SQL runtime engine and SQL query engine. BULK COLLECT pulls entire arrays into PGA memory, and FORALL applies batch updates in a single context switch!
